## 想带来什么体验

希望手机中有一个让人愿意留在身边的小角色：有自己的性格，能表达开心和想念，也能在用户忙的时候安静陪着。产品重点是互动与关系连续性，文字回复由用户配置的模型服务生成。

## 现在可以做什么

- 悬浮陪伴、拖动吸边、四边探头、触摸穿透和月牙恢复。
- 滑动调整角色大小：80%–130%，全身与上下左右探头共用比例，支持保存及恢复默认100%。
- 摸头、抱抱、姿态保持，以及可关闭的日常动作和互动短句。
- 原20层Live2D上的持续心情表情；互动/说话优先，结束后恢复当前心情。
- 人格聊天、现实时间上下文、可查看/修改/删除的长期记忆。
- 可设置间隔与安静时段的主动联系；通知受手机系统后台管理影响。
- 已实现单轮语音和用户发起的一次看屏幕，完整听感和多机表现仍需继续验证。

最新交付记录为44 / `0.10.5-character-size-v0`，已在原真机安装。44版大小调节完成8组固定真机检查；43版持续心情修正另有18项定向检查记录。不同轮次的结果分别记录，不把它们合并成多机或长期验证。长期耗电、发热对照和更多机型仍待补测。

## 实现与取舍

Android原生悬浮窗口、Compose、SQLite、可替换模型/语音接口和Live2D展示分层管理。模型与第三方SDK有独立许可，不将它们宣称为自研。详见[项目取舍](docs/PRODUCT_DECISIONS.md)、[结构](docs/ARCHITECTURE.md)、[后续路线](docs/ROADMAP.md)。
