# 后续路线

宣传视频已于2026年10月17日[发布至B站](https://www.bilibili.com/video/BV1XXJi63Eyh/)，最新交付记录为44版。当前优先整理观众反馈并继续准备试用，暂不把新增功能作为首要任务。项目长期开发，每轮按具体范围推进，不一次跨多个阶段。

| 顺序 | 工作 | 验证方式 |
| --- | --- | --- |
| 当前 | 补齐视频入口与44版说明；整理视频评论中的兴趣、疑问和建议；继续确认许可与试用准备 | 区分视频观感、实际使用反馈和未经验证的推测 |
| 首轮试用 | 计划邀请5–10位目标用户体验约一周，规模与时间并非现有成果 | 安装是否成功、是否愿意继续保留角色、自然互动和打扰感 |
| 稳定性补测 | 长期悬浮、耗电发热、多机兼容、后台与通知 | 实际设备与明确条件的对照，不写未经验证的指标 |
| Phase8完善 | 语音听感、停顿、识别和打断节奏 | 用户方便时真实录音/播放体验 |
| Phase9深化 | 共同经历、记忆纠正、约定与关系连续性 | 固定场景和真实相处反馈 |
| Phase10 | 有限的学习计时、待办或明确请求的工具 | 单独明确授权和范围后开发 |
| Phase11 | 共同习惯、回忆和贴合用户的互动 | 以用户是否觉得开心、愿意留下为依据 |
| Phase12持续 | 稳定性、隐私与公开测试 | 持续记录已验证与待验证事项 |

Phase7D可选特效已经跳过。没有把多角色、换装市场、自动手机操作或商业化作为本次发布条件。

宣传视频发布不等于APK已公开、SDK发行许可已确认或真实用户留存已得到验证。首轮试用人数与周期是计划，尚不作为现有成果。

安静开着悬浮角色也是使用。评价陪伴产品时，除了聊天次数，还应关注是否愿意保留、哪种互动带来愉悦、什么提醒令人烦，以及为什么关闭。没有外部用户或留存数据前，不写“高留存”“验证需求成立”等成果。
