# 隐私与数据流说明（预览稿）

本说明依据当前源码整理，正式发行前需结合最终签名包和实际服务配置复核。

## 保存到手机的数据

会话、长期记忆、关系/心情相关状态及设置保存在应用私有存储。API Key 经 Android Keystore 相关密钥加密保存；聊天和记忆数据库不因此自动成为加密数据库。工程关闭系统应用备份，但这不等于设备被控制或系统被破解后数据仍绝对安全。

## 发送给服务商的数据

文字聊天会向用户配置的模型服务发送当前输入、所需近期上下文、人格和相关记忆/时间信息。主动联系启用后，也可能为生成消息调用配置的模型。身份验证需要将相应Key发送至用户配置的服务地址。

语音识别在用户主动开始后向配置的识别服务发送录音音频；语音合成向配置的合成服务发送要朗读的文本。录音结束不会自动重开下一轮麦克风。一次屏幕查看需要当次授权与确认，确认后的图片/指令发送给配置的视觉服务；不是后台连续读取其他应用。

这些服务商可能收费并有各自数据保留政策。不能把“本地存储聊天”理解为“所有处理都离线”，也不能把本地删除当成已删除服务商端记录。本项目不内置作者的共享Key。

## 查看和删除

- 在聊天中清空当前会话或删除指定会话；其他会话与长期记忆分别保留。
- 在记忆设置查看、修改、删除单条或清空长期记忆；普通聊天需要另行处理。
- 在相应服务设置删除已保存的Key；这不会自动删除会话或撤销服务商端Key。
- 关闭主动联系与退出悬浮陪伴是不同开关，需要时分别关闭。

未将尚未核实的全量导出、云端删除、跨设备迁移写成已支持功能。

## 诊断与反馈

调试构建会在手机私有目录产生提示及阶段诊断记录，提示中可能含注入的上下文；不要上传应用私有目录或完整日志。正式公开测试计划使用 release 构建，并核对调试诊断未开启。

应用里的试用反馈由用户手动填写并主动复制，不自动上传聊天、Key、截图或诊断数据。GitHub Issue 是公开的，请只写最少复现信息，勿贴私人聊天、密钥、完整手机截图或其他人的信息。
