# 试用反馈

动作陪伴可先不配置模型。聊天需自备兼容服务配置，语音与看屏幕分别配置；请先阅读[使用说明](GETTING_STARTED.md)和[隐私说明](PRIVACY.md)。当前还没有正式公开APK下载链接。

## 感受反馈

可以使用应用里的“试用反馈”，手动复制自己愿意公开的内容，再通过项目选定的反馈入口提交。首次公开后也可使用仓库的体验反馈Issue模板。

- 哪一刻让你觉得她可爱、像在陪你？
- 哪一刻感觉重复、生硬或打扰？
- 你愿意继续让她留在屏幕上吗，为什么？
- 如果只能先改一件事，你会选什么？

不需要上传聊天记录来证明感受。说出场景和原因即可。

## 问题复现

写应用版本、手机型号/Android版本、最短操作步骤、预期表现与实际表现。不要公开Key、完整设备序列号、私人聊天或其他应用画面；必要截图先自行遮挡敏感内容。反馈入口不会自动读取诊断文件。

当前单次18项真机检查不是所有设备的长期验证。多机兼容、通知和耗电反馈需说明屏幕/充电/后台设置等条件，不凭感觉直接换算省电百分比。
