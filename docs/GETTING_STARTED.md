# 开始使用

目前仅准备项目展示，没有已经发布的正式下载链接。核心源码暂不公开。不要把其他来源的同名 APK 当成本项目正式发行。

可以先看[手机演示视频](https://www.bilibili.com/video/BV1XXJi63Eyh/)。视频已发布不代表安装包已开放；正式试用方式以本仓库后续公告为准。

## 环境和配置

工程最低 Android API 26，当前只打包 arm64-v8a 和 x86_64；这不代表 Android 8 至今所有设备都已实测。当前真机验证覆盖有限，更多机型仍需反馈。

动作与静态陪伴可以先体验，无需配置模型。文字聊天需填写兼容 Chat Completions 流式协议的 HTTPS 地址、模型名和自己的 Key。语音在语音设置中单独配置；当前识别和合成分别有自己的适配。屏幕理解也需兼容图片的服务。模型及服务商的调用费用和数据政策由用户自行确认。

## 常用操作

| 操作 | 效果 |
| --- | --- |
| 点击角色 | 打开聊天气泡 |
| 长按角色 | 打开动作菜单 |
| 长按角色→调整大小 | 拖动滑条设置80%–130%，松手保存；可恢复默认100% |
| 拖到边缘放下 | 吸边；探头玩法按所在边缘显示 |
| 双击角色 | 进入触摸穿透 |
| 长按上方月牙 | 恢复正常互动 |
| 气泡→更多互动→设置→此刻心情 | 手动选心情或恢复自然变化 |
| 更多互动或设置→退出陪伴 | 收起悬浮角色，聊天和记忆保留 |

抱抱等手动姿态可保持到新互动或业务打断。摸头玩法进入后可在头部轻触/滑动。心情在待机时持续显示，摸头、探头、拖动、手动动作、倾听或说话优先。

44版大小设置也可经“气泡→更多互动→设置→角色大小”进入；全身与四边探头共用同一比例。“预览探头”沿用7秒预览，不改变正式玩法时长。动态角色不可用而采用静态回退时，长按可直接打开大小面板。

## 权限

悬浮窗用于显示角色；通知用于状态、恢复、停止及主动联系提醒。麦克风只在用户主动发起语音时使用；屏幕查看需用户当次授权。无需为普通陪伴授予麦克风或截图权限。

主动联系需单独开启。用户设置的是联系间隔，仍受安静时段、上下文和系统调度限制；不能保证每隔固定分钟准时送达。部分厂商划掉后台、一键清理或强行停止会阻止运行。锁屏展示还由通知通道和系统锁屏设置决定。

## 没有反应时

先在主页检查陪伴是否开启、悬浮窗权限及是否进入穿透；必要时从通知或主页恢复。无法聊天时检查地址、模型、Key和网络。动态渲染异常可先切换静态角色；不需要为了排查而卸载或清空数据。

语音识别不完整时可手动结束或取消；本项目不会自动开启下一轮麦克风。删除 Key、删除聊天与删除长期记忆是不同操作，详见[数据说明](PRIVACY.md)。
