# 当前边界与已知限制

- 主要真机覆盖为 iQOO Neo9 / Android 16。工程 minSdk 不是全部 Android 版本兼容性承诺。
- 持续悬浮的长期稳定性、耗电和发热对照仍待补测；没有低耗电或全天无故障的验证结论。
- 锁屏通知、划后台后的存活和主动联系送达受系统限制；不保证像系统通信应用一样常驻，也不保证固定分钟准时送达。
- 文字和记忆基于已有规则与用户配置模型。时间与有限冲突处理已实现，仍可能出现记忆遗漏、不恰当追问或模型编造，需要实际反馈。
- 语音已实现识别/合成/停顿发送和播放嘴型，但当前三音色的完整听感、复杂噪声和长对话自然度尚未全部验收。
- 开心沿用原闭笑眼；无聊、想你保留原眼形。逻辑闹别扭没有独立新画稿。静态回退也不提供这套持续动态表情。
- “看看这个”是用户主动授权的单次屏幕查看，不是持续读屏，也不是通用自主操作手机的 Agent。
- 当前没有任意导入角色、换装市场、多角色平台、账户云同步、支付或服务端共享模型额度。
- 公开许可与发行包准备尚未完成，不把本目录叫作已正式开源、已上架或已证明用户留存的产品。
